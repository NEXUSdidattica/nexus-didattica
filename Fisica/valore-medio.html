Il Valore Medio

Concetto di valore medio aritmetico, stima del valore più attendibile e 100 esercizi guidati di calcolo applicato.

1. Il Valore Più Attendibile

Quando si effettua una serie di misurazioni ripetute della stessa grandezza fisica nelle medesime condizioni, a causa degli errori casuali è molto probabile ottenere valori leggermente diversi tra loro. La stima migliore del valore vero della grandezza misura è rappresentata dal valore medio (o media aritmetica) delle singole misure effettuate.

2. Formula della Media Aritmetica

Il valore medio xm si calcola dividendo la somma di tutti i valori misurati (x1, x2, ..., xN) per il numero totale N delle misurazioni effettuate.

📊 Formulazione Matematica:

xm = (x1 + x2 + ... + xN) / N

📝 Esercizio Esempio Guidato

Testo: Un alunno misura tre volte la lunghezza di un tavolo ottenendo: 120.4 cm, 120.8 cm e 120.3 cm. Calcola il valore medio della lunghezza.

Risoluzione passo-passo:

  1. Somma dei valori misurati: 120.4 + 120.8 + 120.3 = 361.5 cm.
  2. Conteggio delle misurazioni: N = 3.
  3. Calcolo della media: xm = 361.5 / 3 = 120.5 cm.

🎯 Soluzione: xm = 120.5 cm
