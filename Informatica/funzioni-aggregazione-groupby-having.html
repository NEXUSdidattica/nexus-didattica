Funzioni di Aggregazione, GROUP BY e HAVING

Analisi statistica dei dati, raggruppamento per categorie e filtraggio avanzato dei gruppi in SQL.

1. Le Funzioni di Aggregazione in SQL

Le funzioni di aggregazione eseguono calcoli su un insieme di valori restituiti da una query, restituendo un unico valore riassuntivo. Sono comunemente impiegate per generare statistiche, conteggi e report aziendali o scolastici.

Principali Funzioni di Aggregazione:

1. COUNT(): Conta il numero di righe o valori non nulli.
2. SUM(): Calcola la somma aritmetica dei valori numerici di una colonna.
3. AVG(): Calcola la media aritmetica dei valori.
4. MAX() / MIN(): Individuano rispettivamente il valore massimo e minimo.

2. Raggruppamento e Filtraggio: GROUP BY e HAVING

Esaminiamo come strutturare query complesse suddividendo i dati in categorie:

    Clausola GROUP BY: Raggruppa le righe che condividono gli stessi valori in colonne specifiche, permettendo l'applicazione delle funzioni di aggregazione su ciascun gruppo (es. calcolare la media voti per ogni classe).
    Clausola HAVING: A differenza di WHERE (che filtra le righe prima del raggruppamento), HAVING filtra i gruppi formati dal GROUP BY in base a condizioni sulle funzioni di aggregazione (es. mostra solo le classi con media superiore a 8).

3. Tabella di Sintesi delle Operazioni

Una panoramica rapida delle funzioni di aggregazione e delle clausole di raggruppamento:

Costrutto / Funzione Sintassi di Esempio Funzione Principale
COUNT SELECT COUNT(*) FROM studenti; Restituisce il numero totale di record.
GROUP BY SELECT classe, COUNT(*) FROM studenti GROUP BY classe; Raggruppa i dati in base a una colonna categoriale.
HAVING ... GROUP BY classe HAVING AVG(voto) >= 8; Filtra i gruppi risultanti applicando condizioni aggregate.
