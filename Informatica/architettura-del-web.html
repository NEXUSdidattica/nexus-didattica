L'Architettura del Web e il Modello Client-Server

Funzionamento del World Wide Web, interazione tra client e server, ruoli di URL, DNS, protocollo HTTP e simulatore interattivo.

1. Cos'è il World Wide Web (WWW)

Il World Wide Web (spesso abbreviato in Web) è un sistema di informazioni interconnesse residente su Internet, basato su pagine multimediali collegate tramite collegamenti ipertestuali (link) e accessibili attraverso software applicativi chiamati browser.

Non confondere Internet con il Web:

Internet è l'infrastruttura fisica globale di reti di computer interconnessi. Il Web è invece un servizio applicativo che viaggia sopra Internet (insieme ad altri come la posta elettronica o l'FTP).

2. Il Modello Client-Server

Il funzionamento del Web si regge interamente sull'architettura distribuita Client-Server:

Entità Ruolo e Funzioni Esempi
Client Il dispositivo o programma dell'utente che richiede risorse o servizi, invia le richieste HTTP e visualizza le risposte (rendering grafico). Google Chrome, Firefox, Safari, App mobile.
Server Un computer remoto ad alte prestazioni sempre acceso e in ascolto, che ospita i siti web, elabora le richieste e restituisce i file o i dati richiesti. Server Apache, Nginx, Cloudflare, storage AWS.

3. Cosa accade quando digitiamo un URL?

Ogni volta che inseriamo un indirizzo nella barra del browser (es. https://www.nexusdidattica.it/corsi), si attiva una complessa catena di eventi:

    1. Risoluzione DNS: Il browser interroga un server DNS (Domain Name System) per tradurre il nome di dominio testuale in un indirizzo IP numerico (es. 192.0.2.1).
    2. Connessione TCP/IP e Handshake: Il client si connette al server sull'indirizzo IP risolto, stabilendo il canale di trasporto sicuro (es. TLS/HTTPS).
    3. Invio della Richiesta HTTP: Il browser invia una richiesta formale (es. GET /corsi HTTP/1.1) al server web.
    4. Elaborazione e Risposta: Il server elabora la richiesta e restituisce un codice di stato (es. 200 OK) insieme al codice sorgente HTML/CSS/JS o ai dati richiesti.

4. Simulatore Interattivo: Ciclo di Richiesta Web (Client-Server)

Simula i passaggi compiuti dal browser per interrogare un server web e visualizza il flusso delle richieste passo dopo passo.

web-inspector@nexus-sys:~# Client-Server Workflow Simulator
> Seleziona un'operazione del ciclo web e avvia la simulazione per visualizzare i log sul terminale.
