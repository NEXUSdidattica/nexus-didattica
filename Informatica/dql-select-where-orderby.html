Comandi DQL: SELECT, WHERE e ORDER BY

Interrogazione avanzata dei database relazionali: estrazione selettiva, filtraggio condizionale e ordinamento dei record.

1. Il Ruolo del Data Query Language (DQL)

Il sottoinsieme DQL (Data Query Language) rappresenta la parte più utilizzata di SQL ed è incentrato esclusivamente sull'interrogazione dei dati. L'istruzione principale è la SELECT, che consente di estrarre informazioni da una o più tabelle applicando criteri di proiezione, selezione e ordinamento senza alterare la struttura o il contenuto del database.

Anatomia di una Query DQL:

1. SELECT: Specifica le colonne (attributi) da visualizzare.
2. FROM: Indica la tabella o le tabelle di riferimento.
3. WHERE: Filtra le righe in base a condizioni logiche.
4. ORDER BY: Organizza l'ordinamento del risultato (crescente o decrescente).

2. Analisi delle Clausole Fondamentali

Esaminiamo in dettaglio il funzionamento operativo delle singole componenti:

    SELECT e FROM: Costituiscono il nucleo obbligatorio di ogni query. Tramite l'asterisco (*) è possibile selezionare tutte le colonne, oppure indicare esplicitamente i singoli campi separati da virgola.
    Clausola WHERE: Permette di applicare filtri booleani alle tuple utilizzando operatori di confronto (=, <>, >, <) e operatori logici (AND, OR, NOT).
    Clausola ORDER BY: Ordina il set di risultati in base a una o più colonne. L'ordinamento di default è crescente (ASC), mentre la parola chiave DESC imposta l'ordine decrescente.

3. Tabella di Sintesi delle Clausole DQL

Una panoramica rapida delle clausole di interrogazione e della loro sintassi:

Clausola Sintassi di Esempio Funzione Principale
SELECT SELECT nome, cognome FROM studenti Seleziona le colonne desiderate dalla tabella indicata.
WHERE ... WHERE classe = '2ªSA' Filtra i record restituendo solo quelli che soddisfano la condizione.
ORDER BY ... ORDER BY cognome ASC Ordina alfabeticamente o numericamente il risultato finale.

4. Simulatore Interattivo: Interrogazioni DQL

Sperimenta l'esecuzione di query DQL complesse con filtri condizionali e ordinamenti in un database simulato.
