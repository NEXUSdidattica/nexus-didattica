Introduzione al Linguaggio SQL

Struttura, comandi fondamentali e categorie operative (DDL e DML) per interagire con i database relazionali.

1. Cos'è l'SQL

Il linguaggio SQL (Structured Query Language) è lo standard internazionale riconosciuto per la gestione, l'interrogazione e la manipolazione dei database relazionali (RDBMS). Sviluppato inizialmente da IBM negli anni '70, permette di comunicare con sistemi come MySQL, PostgreSQL, Oracle e SQLite mediante istruzioni dichiarative.

Le Macro-Famiglie dei Comandi SQL:

1. DDL (Data Definition Language): Comandi per definire e modificare la struttura del database (es. CREATE, ALTER, DROP).
2. DML (Data Manipulation Language): Comandi per inserire, aggiornare, cancellare e interrogare i dati all'interno delle tabelle (es. SELECT, INSERT, UPDATE, DELETE).

2. Sintassi Fondamentale delle Interrogazioni (Query)

Il comando cardine dell'SQL è la SELECT, utilizzata per estrarre informazioni da una o più tabelle in base a criteri specificati:

    Clausola SELECT: Specifica le colonne o gli attributi che desideriamo visualizzare nel risultato dell'interrogazione.
    Clausola FROM: Specifica la tabella o l'insieme di tabelle da cui estrarre i dati.
    Clausola WHERE: Filtra le righe restituite in base a condizioni logiche (es. ETA > 18).

3. Tabella di Sintesi dei Comandi Principali

Una panoramica rapida dei comandi DDL e DML più comuni:

Categoria Comando Funzione Principale
DDL CREATE TABLE Definisce una nuova tabella specificandone campi, tipi di dato e vincoli.
DML SELECT Interroga il database estraendo set di record filtrati e ordinati.
DML INSERT INTO Aggiunge nuovi record (tuple) all'interno di una tabella esistente.

4. Simulatore Interattivo: Esecuzione Query SQL

Sperimenta direttamente l'esecuzione di istruzioni SQL di base e osserva la risposta del motore di database.

sql-client@nexus-sys:~# Interactive SQL Shell
