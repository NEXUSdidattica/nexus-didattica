Comandi DML: INSERT, UPDATE e DELETE

Manipolazione dei dati all'interno delle tabelle: inserimento, aggiornamento e cancellazione delle tuple.

1. Il Ruolo del Data Manipulation Language (DML)

Il sottoinsieme DML (Data Manipulation Language) raggruppa le istruzioni SQL dedicate alla gestione e alla modifica dei dati contenuti nelle tabelle di un database relazionale. A differenza del DDL, che agisce sulla struttura, il DML opera direttamente sulle righe (tuple).

Le Operazioni DML Fondamentali:

1. INSERT: Aggiunge nuove tuple all'interno di una tabella.
2. UPDATE: Modifica i valori di uno o più attributi nelle tuple esistenti.
3. DELETE: Rimuove tuple specifiche da una tabella in base a condizioni logiche.

2. Analisi dei Comandi Principali

Esaminiamo in dettaglio la sintassi e l'utilizzo operativo delle tre istruzioni:

    INSERT INTO: Permette di inserire record specificando i valori corrispondenti alle colonne della tabella. È fondamentale rispettare l'ordine dei campi e i vincoli di integrità (es. chiavi primarie e valori non nulli).
    UPDATE: Utilizzato per aggiornare i dati esistenti. Viene solitamente associato alla clausola WHERE per circoscrivere la modifica solo alle righe interessate, evitando aggiornamenti indesiderati su intere tabelle.
    DELETE FROM: Cancella le righe che soddisfano la condizione specificata nella clausola WHERE. Senza clausola condizionale, l'operazione svuota interamente la tabella preservandone comunque la struttura.

3. Tabella di Sintesi delle Istruzioni DML

Una panoramica rapida dei comandi di manipolazione e dei loro effetti:

Comando Sintassi di Base Effetto sui Dati
INSERT INSERT INTO nome (col1) VALUES (val1); Aggiunge una nuova riga con i valori specificati.
UPDATE UPDATE nome SET col1 = val1 WHERE condizione; Modifica i valori nelle righe che soddisfano il filtro.
DELETE DELETE FROM nome WHERE condizione; Elimina le righe individuate dalla condizione logica.

4. Simulatore Interattivo: Manipolazione Dati DML

Sperimenta l'esecuzione di comandi DML per inserire, aggiornare o cancellare record in un database simulato.

dml-engine@nexus-sys:~# Data Management Shell
