Array Monodimensionali (Vettori)

Strutture dati lineari omogenee: memorizzazione contigua in RAM, indicizzazione numerica e operazioni di scansione con cicli.

1. Che cos'è un Array Monodimensionale?

Un array monodimensionale (comunemente chiamato vettore) è una struttura dati statica e omogenea che consente di memorizzare una sequenza finita di elementi dello stesso tipo (es. tutti interi, tutti float o tutti caratteri) sotto un unico nome identificativo. Ciascun elemento è collocato in celle di memoria contigue ed è accessibile direttamente tramite un numero intero detto indice.

2. Indicizzazione e Rappresentazione in Memoria

Nella maggior parte dei linguaggi di programmazione moderni (come C, C++, Java e JavaScript), l'indicizzazione parte da 0. Se un vettore ha dimensione $N$, gli indici validi vanno da $0$ a $N-1$.

Indice (i) 0 1 2 3 4
Valore in Celle 12 45 7 89 23
Proprietà Chiave:
  • Accesso Diretto ($O(1)$): Conoscendo l'indirizzo base della memoria e l'indice, il processore calcola istantaneamente la posizione fisica del dato.
  • Omogeneità: Non è possibile inserire dati di tipo differente nello stesso vettore.

3. Simulatore Interattivo: Manipolatore di Vettori

Seleziona un'operazione comune sui vettori per visualizzare l'elaborazione passo-passo eseguita su un array di prova.

array-eval@nexus-core:~# 1D Array Processor Simulator
