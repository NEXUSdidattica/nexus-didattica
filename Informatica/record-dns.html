Tipologie di Record DNS & File di Zona

Analisi dei principali record di configurazione (A, AAAA, CNAME, MX, TXT, NS) e simulatore interattivo di interrogazione dei record.

1. Cosa sono i Record DNS e i File di Zona

All'interno dei server DNS autoritativi, le informazioni di mappatura sono organizzate in file di zona (Zone Files). Ciascuna zona contiene una serie di direttive e record di risorsa (Resource Records) che specificano come associare nomi di host a indirizzi di rete, servizi di posta o chiavi di sicurezza.

Anatomia di un Record DNS standard:

[Nome Host] [TTL] [Classe] [Tipo Record] [Valore / Destinazione]
Esempio: www.nexusdidattica.it. 3600 IN A 172.67.182.11

2. Tabella dei Principali Tipi di Record

I record più comunemente impiegati nella gestione di un dominio web e dei relativi servizi comprendono:

Tipo Record Nome Completo Funzione e Utilizzo Principale Esempio di Valore
A Address Record Mappa un nome di dominio direttamente a un indirizzo IPv4 numerico a 32 bit. 192.0.2.45
AAAA IPv6 Address Record Mappa un nome di dominio a un indirizzo IPv6 a 128 bit di nuova generazione. 2001:db8::1
CNAME Canonical Name Crea un alias: punta un sottodominio a un altro dominio canonico (non può essere usato sulla radice). ghs.google.com
MX Mail Exchange Indica i server di posta elettronica responsabili della ricezione delle email per il dominio, associati a una priorità. 10 mail.nexusdidattica.it
TXT Text Record Memorizza stringhe di testo arbitrarie, spesso impiegate per verifiche di proprietà o sicurezza (SPF, DKIM, DMARC). v=spf1 include:_spf...
NS Name Server Specifica quali server DNS sono autoritativi per gestire la zona di quel dominio specifico. ns1.cloudflare.com

3. Il parametro TTL (Time To Live)

Il TTL espresso in secondi indica per quanto tempo i resolver intermedi e la cache locale dei client possono memorizzare la risposta prima di dover interrogare nuovamente il server autoritativo. Un TTL basso facilita i cambi rapidi di IP (es. configurazioni di failover o migrazioni), mentre un TTL alto riduce il carico complessivo sui server DNS.

4. Simulatore Interattivo: Interrogazione Record di Zona (Dig Tool)

Simula l'esecuzione di comandi di ispezione dei record DNS su una zona di test e osserva i risultati restituiti dal server.

dns-inspector@nexus-sys:~# DNS Records Query Simulator
> Seleziona un tipo di record DNS e avvia l'interrogazione per visualizzare l'output del server di zona.
