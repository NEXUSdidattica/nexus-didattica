La Maschera di Sottorete (Subnet Mask) e CIDR

Funzionamento della subnet mask, operazione booleana AND, notazione CIDR e simulatore interattivo di calcolo di rete.

1. Cos'è la Maschera di Sottorete

La Maschera di Sottorete (o Subnet Mask) è un numero a 32 bit che accompagna un indirizzo IP per separare la porzione di rete (NetID) dalla porzione di host (HostID). Essa è costituita da una sequenza continua di bit a 1 (che coprono il NetID) seguita da una sequenza continua di bit a 0 (che coprono l'HostID).

Proprietà e Operazione AND:
    Operazione Logica AND: Per determinare l'indirizzo di rete, il router applica l'operatore booleano AND bit a bit tra l'indirizzo IP e la Subnet Mask.
    Bit a 1 nella Mask: Lasciano immutato il valore del bit dell'indirizzo IP corrispondente (selezionano la rete).
    Bit a 0 nella Mask: Anzeranno a 0 il bit dell'indirizzo IP corrispondente (isoclanano gli host).

2. Notazione CIDR (Classless Inter-Domain Routing)

Per semplificare la scrittura delle subnet mask lunghe, si utilizza la notazione CIDR, che aggiunge un suffisso numerico indicante il numero totale di bit impostati a 1 nella maschera (es. /24 equivale a 255.255.255.0).

Notazione CIDR Subnet Mask Decimale Bit di Rete / Host Numero di Host Utilizzabili
/24 255.255.255.0 24 bit rete / 8 bit host 254
/25 255.255.255.128 25 bit rete / 7 bit host 126
/26 255.255.255.192 26 bit rete / 6 bit host 62
/28 255.255.255.240 28 bit rete / 4 bit host 14

3. Simulatore Interattivo: Calcolo Subnet e Operazione AND

Seleziona una combinazione IP e Subnet Mask per simulare l'operazione di calcolo dell'indirizzo di rete e degli host disponibili.

subnet-calc@nexus-sys:~# CIDR & Subnet Bitwise Calculator
> Seleziona una configurazione e avvia il calcolo per verificare la sottorete e i parametri CIDR.
