La CLI (Command Line Interface)

Interazione testuale con il sistema operativo, interprete dei comandi (Shell), script di automazione e gestione avanzata del file system.

1. Che cos'è la CLI e la Shell?

La CLI (Command Line Interface) è un'interfaccia utente testuale che permette di impartire istruzioni al computer digitando comandi da tastiera. Il software responsabile dell'interpretazione ed esecuzione di questi comandi prende il nome di Shell (es. Bash, Zsh, PowerShell).

2. Vantaggi rispetto all'Interfaccia Grafica (GUI)

Sebbene le interfacce grafiche (GUI) siano più intuitive per l'utente comune, la CLI offre vantaggi cruciali per programmatori e amministratori di sistema:

  • Efficienza e Velocità: Esecuzione di operazioni complesse con combinazioni rapide di tasti e argomenti.
  • Automazione (Scripting): Possibilità di combinare più comandi in file di script per automatizzare processi ripetitivi o backup.
  • Leggerezza: Richiede pochissime risorse di sistema, ideale per server remoti (es. via SSH).
Sintassi Generale di un Comando: $\text{comando} + [\text{opzioni/flag}] + [\text{argomenti}]$. Esempio: `ls -l /var/log` per elencare dettagliatamente i file di log.

3. Simulatore Interattivo di Riga di Comando (CLI)

Digita i comandi nel terminale sottostante per simulare l'interazione con una vera shell di sistema (prova comandi come help, ls, pwd, clear o whoami).

samuel@nexus-terminal:~ Bash Shell v5.2
Benvenuto nel simulatore CLI di NEXUS didattica. Digita "help" per visualizzare l'elenco dei comandi disponibili.
