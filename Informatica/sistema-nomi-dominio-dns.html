Il Sistema dei Nomi di Dominio (DNS)

Architettura distribuita di traduzione degli indirizzi, gerarchia dei server, record di zona e simulatore interattivo di lookup.

1. Cos'è il DNS e perché è essenziale

Il DNS (Domain Name System) è un database distribuito e gerarchico che svolge la funzione di "rubrica telefonica" di Internet: converte i nomi di dominio umanamente leggibili (es. www.nexusdidattica.it) in indirizzi IP numerici (es. 172.67.182.11) comprensibili dai dispositivi di rete.

La struttura di un Dominio (FQDN):

Un nome di dominio completo (Fully Qualified Domain Name) si legge da destra verso sinistra: radice . ➔ TLD (.it) ➔ Dominio di secondo livello (nexusdidattica) ➔ Host/Sottodominio (www).

2. La Gerarchia dei Server DNS

La risoluzione di un nome non avviene su un unico server centrale, ma attraversa una catena piramidale di entità specializzate:

Livello della Gerarchia Ruolo e Funzioni Esempi
Root Name Servers I server radice collocati all'apice del sistema. Indicano ai resolver dove trovare i server TLD specifici. Ne esistono 13 cluster logici nel mondo. a.root-servers.net
TLD Name Servers (Top-Level Domain) Gestiscono le estensioni finali dei domini e reindirizzano le richieste verso i server autoritativi di competenza. .com, .it, .org, .edu
Authoritative Name Servers I server ufficiali gestiti dai registrar o dai provider che contengono i record DNS reali e definitivi per quel singolo dominio. Server DNS di Aruba, Cloudflare, AWS Route 53.

3. I Principali Record DNS

I record DNS memorizzati nei file di zona definiscono come associare i nomi di dominio alle risorse di rete:

    Record A (Address): Associa un nome di dominio a un indirizzo IP versione 4 (IPv4).
    Record AAAA: Associa un nome di dominio a un indirizzo IP versione 6 (IPv6).
    Record CNAME (Canonical Name): Crea un alias, collegando un sottodominio a un altro nome di dominio canonico.
    Record MX (Mail Exchange): Specifica i server di posta elettronica incaricati di ricevere le email per quel dominio.

4. Simulatore Interattivo: Processo di Lookup DNS e Risoluzione

Simula l'interrogazione ricorsiva e iterativa compiuta da un resolver per scoprire l'indirizzo IP associato a un dominio.

dns-lookup@nexus-sys:~# DNS Query & Resolution Simulator
> Seleziona una fase del lookup DNS e avvia la simulazione per visualizzare i log sul terminale.
