Il Concetto di File System

Astrazione della memoria di massa, gestione dei file, attributi, operazioni logiche e organizzazione gerarchica delle directory.

1. Cos'è un File System?

Il File System è il sottosistema fondamentale di un sistema operativo che si occupa di organizzare, memorizzare, manipolare, proteggere e recuperare i dati sui dispositivi di memoria di massa (hard disk, SSD, unità flash). La sua funzione principale è quella di offrire un'astrazione logica, nascondendo i dettagli fisici di basso livello (come settori, tracce e testine magnetiche) e presentando all'utente e ai programmi una visione basata su file e directory.

2. Anatomia di un File: Attributi e Struttura

Un file è una sequenza logica di informazioni (bit, byte, righe o record) definita dal suo creatore. Per gestire correttamente ciascun file, il sistema operativo associa una serie di metadati noti come attributi del file:

  • Nome e Identificatore (ID): Il nome leggibile dall'utente e un tag numerico univoco all'interno del file system.
  • Tipo e Dimensione: Informazioni sul formato del file e sulla quantità di byte attualmente occupati.
  • Protezione e Permessi: Regole di accesso che stabiliscono chi può leggere, scrivere o eseguire il file (es. owner, group, others).
  • Timestamp: Date e orari relativi alla creazione, all'ultima modifica e all'ultimo accesso.
Operazioni logiche sui file: Il sistema operativo mette a disposizione delle applicazioni un insieme di chiamate di sistema (system call) per la gestione: $$\text{create} \rightarrow \text{open} \rightarrow \text{read/write} \rightarrow \text{seek} \rightarrow \text{close} \rightarrow \text{delete}$$

3. Organizzazione Gerarchica delle Directory

I file sono raggruppati all'interno di directory (o cartelle), le quali a loro volta possono contenere altre sottodirectory, formando una struttura ad albero gerarchico. Ogni file all'interno del file system è individuabile univocamente tramite un percorso (path), che può essere assoluto (partendo dalla radice / o C:\) o relativo (partendo dalla directory di lavoro corrente).

4. Simulatore Interattivo: Esplorazione e Metadati del File System

Seleziona un file di esempio per visualizzarne i metadati, i permessi e la struttura logica gestita dal file system.

fs-explorer@nexus-core:~# Virtual File System Metadata Viewer
