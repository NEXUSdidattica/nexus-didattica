Scambio di Dati XML

Analisi approfondita della struttura XML, tag personalizzati, attributi, alberi DOM e 100 esercizi pratici guidati di formattazione.

1. Introduzione a XML (Extensible Markup Language)

XML è un linguaggio di marcatura estensibile progettato per memorizzare e trasportare dati in modo strutturato. A differenza dell'HTML, che definisce l'aspetto visivo di una pagina, XML definisce la semantica e la gerarchia dei dati attraverso tag personalizzati definiti dall'utente.

<?xml version="1.0" encoding="UTF-8"?> <scuola> <studente id="1"> <nome>Samuel Fassi</nome> <classe>2ª Scienze Applicate</classe> <materia>Informatica</materia> </studente> </scuola>

2. Regole Sintattiche e Componenti Principali

Per essere considerato "ben formato" (well-formed), un documento XML deve rispettare rigorose specifiche strutturali:

Componente Regola / Sintassi Descrizione e Funzione
Prologo XML <?xml version="1.0" encoding="UTF-8"?> Opzionale ma raccomandato all'inizio del file per specificare versione e codifica dei caratteri.
Elemento Radice <root>...</root> Ogni documento XML deve contenere un unico elemento radice che racchiude tutti gli altri nodi.
Tag e Chiusura <tag>Valore</tag> Tutti i tag aperti devono essere rigorosamente chiusi e nidificati correttamente (case-sensitive).
Attributi <tag attributo="valore"> Forniscono metadati aggiuntivi associati a uno specifico elemento, racchiusi tra apici.

3. Simulatore Interattivo: Analizzatore di Strutture XML

Seleziona una modalità di elaborazione per visualizzarne la sintassi e la gestione ad albero.

xml-validator@nexus-core:~# XML Inspector
