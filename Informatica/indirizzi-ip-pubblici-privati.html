Indirizzi IP Pubblici e Privati (RFC 1918)

Differenze strutturali, intervalli di indirizzamento privato, meccanismo di traduzione NAT e simulatore interattivo.

1. IP Pubblico vs IP Privato

Nel protocollo IPv4 si distingue tra due categorie fondamentali di indirizzi:

    Indirizzo IP Pubblico: È univoco a livello globale ed è visibile direttamente su Internet. Viene assegnato da un ISP (Internet Service Provider) ed è utilizzato dai server web e dai router di confine.
    Indirizzo IP Privato: Viene utilizzato all'interno di reti locali (LAN, intranet domestiche o aziendali). Non sono instradabili direttamente su Internet, consentendo il riutilizzo degli stessi indirizzi in milioni di case diverse.

2. Intervalli di Indirizzi Privati (RFC 1918)

Classe / Tipo Intervallo IP Numero di Indirizzi Uso Tipico
Classe A 10.0.0.0 – 10.255.255.255 16.777.216 (Blocco /8) Grandi reti aziendali
Classe B 172.16.0.0 – 172.31.255.255 1.048.576 (Blocchi /12) Reti dipartimentali / medie imprese
Classe C 192.168.0.0 – 192.168.255.255 65.536 (Blocchi /16) Reti domestiche e SOHO (es. 192.168.1.x)

3. Il Ruolo del NAT (Network Address Translation)

Poiché i dispositivi con IP privato non possono navigare direttamente sul Web, interviene il router di casa o aziendale tramite il meccanismo del NAT. Il router traduce l'indirizzo IP privato sorgente del pacchetto in un unico indirizzo IP pubblico (quello assegnato dall'ISP), tenendo traccia delle connessioni in una tabella di stato.

4. Simulatore Interattivo: Classificazione IP e Traduzione NAT

Inserisci o seleziona un indirizzo IP per verificare se appartiene a una categoria pubblica o privata e simulare il comportamento del NAT.

nat-analyzer@nexus-sys:~# Public/Private IP & NAT Simulator
> Seleziona un indirizzo IP e avvia l'analisi per verificare la classificazione e il routing NAT.
