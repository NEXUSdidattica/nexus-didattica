Matematica / Frazioni Algebriche

Lezione 1: Condizioni di Esistenza (C.E.)

Imparare a determinare il dominio di una frazione algebrica imponendo che il denominatore sia diverso da zero.

1. Che cos'è una Frazione Algebrica?

Una frazione algebrica è un rapporto tra due polinomi A/B, dove il numeratore è A e il denominatore è B (con B che contiene almeno una variabile).

🔹 Regola fondamentale per l'esistenza:
In matematica la divisione per zero è impossibile. Di conseguenza, una frazione algebrica ha significato soltanto se il suo denominatore è diverso da zero:

Denominatore ≠ 0 (C.E.: B ≠ 0)

2. Procedimento per determinare le C.E.

  1. Prendere in considerazione SOLO il denominatore (il numeratore può assumere qualsiasi valore, anche zero).
  2. Scomporre in fattori il denominatore se si tratta di un polinomio di grado superiore al primo.
  3. Porre ciascun fattore del denominatore diverso da zero e risolvere le relative disequazioni.

📝 Esercizio Esempio Guidato

Testo: Trova le Condizioni di Esistenza della frazione algebrica: (2x + 1) / (x² - 9).

Risoluzione passo-passo:

  1. Isoliamo il denominatore: x² - 9.
  2. Scomponiamo usando la differenza di quadrati: (x - 3)(x + 3).
  3. Imponiamo che la scomposizione sia diversa da zero: (x - 3)(x + 3) ≠ 0.
  4. Poniamo ciascun fattore diverso da zero:
    • x - 3 ≠ 0 => x ≠ 3
    • x + 3 ≠ 0 => x ≠ -3

🎯 Risultato C.E.: x ≠ 3 e x ≠ -3 (oppure x ≠ ±3)
