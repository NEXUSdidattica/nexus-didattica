Lezione 4: Espressioni Complesse

Risoluzione di espressioni articolate con parentesi nidificate, potenze negative e decimali periodici.

1. Strategia di Risoluzione delle Espressioni Articolate

Quando un'espressione contiene sia frazioni algebriche che numeri decimali (limitati o periodici) e potenze negative, il primo fondamentale passaggio consiste nel **convertire tutti i decimali in frazioni generatrici**.

🔹 Conversioni Utili da Ricordare:
• 0,333... (0,3̄) = 1/3  |  0,666... (0,6̄) = 2/3
• 0,166... (0,16̄) = (16-1)/90 = 15/90 = 1/6  |  1,333... (1,3̄) = (13-1)/9 = 12/9 = 4/3
• 0,5 = 1/2  |  0,75 = 3/4

🔹 Gerarchia Operativa:
1. Convertire i decimali periodici in frazioni generatrici e trasformare gli esponenti negativi (es. (A/B)⁻ⁿ = (B/A)ⁿ).
2. Calcolare le Condizioni di Esistenza (C.E.) di tutti i denominatori visibili o generati dall'inversione delle divisioni.
3. Eseguire prima le operazioni nelle parentesi tonde ( ), poi quadre [ ] e infine graffe { }.

📝 Esercizio Esempio Guidato (Lungo con Periodici)

Testo: Risolvi: { [ (0,3̄ + 1/2)² : 0,16̄ - (1 - 0,6̄) · 9/4 ] : [ (5/3 - 0,75) · 1,3̄ + 7/9 ] }² · (3/10)⁻¹.

Risoluzione guidata:

  1. Convertiamo i numeri decimali in frazioni:
    0,3̄ = 1/3, 0,16̄ = 1/6, 0,6̄ = 2/3, 0,75 = 3/4, 1,3̄ = 4/3, (3/10)⁻¹ = 10/3.
  2. Sostituiamo e risolviamo le tonde:
    • (1/3 + 1/2) = 5/6
    • (1 - 2/3) = 1/3
    • (5/3 - 3/4) = 11/12
  3. Risolviamo le quadre:
    • Prima quadra: [ (5/6)² : 1/6 - 1/3 · 9/4 ] = [ 25/36 · 6 - 3/4 ] = [ 25/6 - 3/4 ] = 41/12.
    • Seconda quadra: [ 11/12 · 4/3 + 7/9 ] = [ 11/9 + 7/9 ] = 18/9 = 2.
  4. Calcolo nelle graffe ed elevamento a potenza:
    { 41/12 : 2 }² = (41/24)² = 1681/576.
  5. Moltiplicazione finale:
    1681/576 · 10/3 = 8405/864.

🎯 Risultato finale: 8405 / 864
