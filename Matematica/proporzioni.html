Lezione 1: Le Proporzioni

Concetto di proporzione, terminologia (estremi e medi), proprietà fondamentale e proprietà derivate con 100 esercizi guidati passo passo.

1. Cos'è una Proporzione?

Una proporzione è un'uguaglianza tra due rapporti. Si scrive nella forma:

A : B = C : D

Si legge: "A sta a B come C sta a D".

  • A e D si chiamano Estremi.
  • B e C si chiamano Medi.
  • A e C sono i Antecedenti; B e D sono i Conseguenti.

2. La Proprietà Fondamentale

In ogni proporzione valida, il **prodotto dei medi è uguale al prodotto degli estremi**:

📐 Proprietà Fondamentale:
Se A : B = C : D ⇒ A × D = B × C

3. Calcolo dell'Incognita (X)

Per trovare il termine incognito X in una proporzione:

  • Se X è un Estremo: X = (Prodotto dei Medi) / (Estremo noto)
  • Se X è un Medio: X = (Prodotto degli Estremi) / (Medio noto)
  • Proporzione Continua (A : X = X : B): X = √(A × B)

4. Proprietà delle Proporzioni

🔄 Invertire: Scambiando ogni antecedente con il proprio conseguente si ottiene ancora una proporzione valida.
A : B = C : D ⇒ B : A = D : C
🔀 Permutare: Scambiando tra loro i due medi o i due estremi la proporzione rimane valida.
Permutare i medi: A : C = B : D | Permutare gli estremi: D : B = C : A
➕ Comporre e Scomporre:
(A + B) : A = (C + D) : C oppure (A + B) : B = (C + D) : D
(A - B) : A = (C - D) : C (con A > B e C > D)

📝 Esercizio Esempio Guidato

Testo: Calcola il valore dell'incognita $x$ nella proporzione: 12 : x = 8 : 10.

Risoluzione passo-passo:

  1. L'incognita $x$ si trova nella posizione di un medio.
  2. Applicando la formula: $x = \frac{\text{Prodotto degli Estremi}}{\text{Medio Noto}}$.
  3. Moltiplichiamo gli estremi $12 \times 10 = 120$.
  4. Dividiamo per il medio noto $8$: $x = \frac{120}{8} = 15$.

🎯 Risultato: x = 15.
