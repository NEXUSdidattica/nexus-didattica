Il Valore Assoluto (Modulo)

Lezione 1: Definizione geometrica e analitica, proprietà fondamentali e 100 esercizi guidati.

1. Cos'è il Valore Assoluto? (Significato Geometrico)

In matematica, il valore assoluto (o modulo) di un numero reale $x$, indicato con il simbolo \(\lvert x \rvert\), rappresenta la sua distanza dallo zero sulla retta dei numeri reali, indipendentemente dal verso.

$$\lvert 5 \rvert = 5 \quad \text{e} \quad \lvert -5 \rvert = 5$$

2. Definizione Analitica (A Pezzi)

$$\lvert x \rvert = \begin{cases} x & \text{se } x \ge 0 \\ -x & \text{se } x < 0 \end{cases}$$
