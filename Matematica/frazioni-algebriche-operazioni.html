Lezione 3: Operazioni e Potenze

Esegui addizioni, sottrazioni, moltiplicazioni, divisioni e potenze con frazioni algebriche trovando il m.c.m. e applicando le C.E.

1. Le Regole delle Operazioni e delle Potenze

L'esecuzione delle operazioni segue le medesime regole delle frazioni numeriche, estese all'uso dei polinomi e delle proprietà delle potenze.

🔹 Regole sintetiche per operare:
• Somma / Sottrazione: Scomporre i denominatori, trovare il m.c.m. ed eseguire la somma al numeratore.
• Moltiplicazione: Semplificare in croce e moltiplicare numeratore per numeratore, denominatore per denominatore.
• Divisione: Moltiplicare la prima frazione per l'inversa della seconda.
• Potenza ad esponente positivo: Elevare separatamente numeratore e denominatore: (A / B)ⁿ = Aⁿ / Bⁿ.
• Potenza ad esponente negativo: Capovolgere la frazione e cambiare il segno all'esponente: (A / B)⁻ⁿ = (B / A)ⁿ.

📝 Esercizio Esempio Guidato (Potenze e Divisione)

Testo: Calcola: [ (x - 1) / (2x) ]⁻² : [ (x - 1) / x ]².

Risoluzione guidata:

  1. C.E.: x ≠ 0 e x ≠ 1.
  2. Capovolgiamo la prima frazione per via dell'esponente negativo: [ (2x) / (x - 1) ]².
  3. Applichiamo le potenze: (4x²) / (x - 1)² : (x - 1)² / x².
  4. Trasformiamo in moltiplicazione capovolgendo il divisore: [ (4x²) / (x - 1)² ] · [ x² / (x - 1)² ].
  5. Moltiplichiamo i termini: (4x⁴) / (x - 1)⁴.

🎯 Risultato: 4x⁴ / (x - 1)⁴ con C.E.: x ≠ 0, x ≠ 1
