Lezione 6: Disequazioni Letterali

Studio e discussione delle disequazioni contenenti parametri algebrici con 100 esercizi svolti.

Cosa sono le Disequazioni Letterali?

Una disequazione è letterale (o parametrica) quando, oltre all'incognita principale $x$, contiene una o più lettere che rappresentano costanti o parametri (es. $a, b, k$).

Discussione del Parametro

Ridotta la disequazione alla forma $ax > b$, la soluzione varia in base al segno di $a$:

  • Se $a > 0$: Si divide per $a$ senza cambiare il verso $\implies x > \frac{b}{a}$.
  • Se $a < 0$: Si divide per $a$ e si inverte il verso $\implies x < \frac{b}{a}$.
  • Se $a = 0$: Si sostituisce $0$ al posto di $a$, ottenendo $0x > b$:
    • Se $b < 0 \implies$ la disequazione è Sempre Vera ($\forall x \in \mathbb{R}$).
    • Se $b \ge 0 \implies$ la disequazione è Impossibile ($\nexists x \in \mathbb{R}$).
