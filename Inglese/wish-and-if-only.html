Wish e If Only

Guida completa all'uso di Wish e If Only in inglese: strutture e regole per esprimere desideri, rimpianti passati e lamentele sul comportamento altrui.

1. Che cosa esprimono Wish e If Only?

Le espressioni wish (desiderare / volere che) e if only (magari! / se solo...) vengono utilizzate in inglese per parlare di situazioni ipotetiche e stati d'animo di insoddisfazione. If only è molto più enfatico e drammatico rispetto a *wish*, ma grammaticalmente seguono le stesse regole di backshift temporale (spostamento indietro dei tempi verbali), simili a quelle dei periodi ipotetici.

2. Esprimere Desideri nel Presente (Situazioni Irreali ORA)

Quando vogliamo che una situazione presente sia diversa ma sappiamo che non è così, utilizziamo wish / if only + Past Simple (o *were* per tutte le persone con il verbo to be).

🇬🇧 Struttura per il Presente:

Subject + wish / If only + Past Simple (o were)

Contesto Esempio con "Wish" Esempio con "If Only"
Stato / Condizione I wish I spoke fluent French. (Ma non lo parlo) If only I were rich! (Ma non lo sono)
Abilità / Capacità She wishes she could play the piano. If only we had more time today.

3. Esprimere Rimpianti nel Passato (Situazioni Passate Immodificabili)

Per parlare di un evento passato che ci dispiace o di cui ci pentiamo (esattamente come nel Third Conditional), si utilizza wish / if only + Past Perfect (had + participio passato).

    I wish I had studied harder for the test yesterday. (Ma non l'ho fatto)
    If only we hadn't missed the train! (Ma lo abbiamo perso)

4. Esprimere Lamentele e Fastidio nel Futuro/Presente (*Would*)

Quando vogliamo lamentarci di un comportamento fastidioso, ripetitivo o di una situazione che vorremmo cambiasse per iniziativa altrui (ma che probabilmente non cambierà), usiamo wish / if only + would + forma base.

⚠️ Regola fondamentale del "Would"

Non puoi usare *wish... would* riferito a te stesso (non puoi dire *"I wish I would win"*). Si usa esclusivamente per esprimere fastidio verso azioni compiute da altre persone, cose o dal tempo atmosferico (*I wish it would stop raining*).

  • I wish you would stop making that noise! (Lamentele sul comportamento)
  • If only he would call me back.
