Relative Clauses

Guida completa alle frasi relative in inglese: pronomi, differenze tra Defining e Non-Defining Clauses e clausole ridotte.

1. Introduzione e Pronomi Relativi

Le relative clauses (frasi relative) servono a collegare un'informazione extra a un nome (persona, animale, cosa o luogo) menzionato nella frase principale, evitandone la ripetizione. Sono introdotte dai relative pronouns (pronomi relativi).

Pronome Uso / Riferimento Esempio
Who / That Persone (Soggetto o Oggetto) The developer who/that wrote the code is smart.
Which / That Animali o Cose (Soggetto o Oggetto) The app which/that I downloaded works well.
Whose Possesso (per persone, animali e cose) The student whose project won is Samuel.
Whom Persone (solo come Oggetto, formale) The girl whom you met yesterday is my classmate.
Where Luoghi The mountain where we hiked was amazing.
When Tempo I remember the day when we launched the site.

2. Defining Relative Clauses (Frasi Relative Delimitative)

Le Defining Relative Clauses forniscono informazioni essenziali per identificare a quale persona o cosa ci si riferisce. Senza questa clausola, la frase principale perderebbe significato o sarebbe incompleta.

  • Non si mettono mai tra virgole.
  • Il pronome relativo (who, which, that) può essere omesso se funge da complemento oggetto della frase relativa.

Esempio con omissione:
• Completo: This is the script that I wrote.
• Omesso: This is the script I wrote. (Questo è lo script [che] ho scritto).

3. Non-Defining Relative Clauses (Frasi Relative Esplicative)

Le Non-Defining Relative Clauses aggiungono informazioni extra e non essenziali su una persona o cosa già chiaramente identificata. Se la clausola viene rimossa, la frase principale rimane comunque di senso compiuto.

  • Sono sempre racchiuse tra virgole (o precedute da una virgola se si trovano alla fine).
  • Il pronome relativo non può mai essere omesso.
  • Il pronome that non può essere usato in questo tipo di clausole (si usa who per le persone e which per le cose).

Esempio:
• Rome, which is the capital of Italy, is very ancient. (Roma, che è la capitale d'Italia, è antichissima).

4. Reduced Relative Clauses (Clausole Relative Ridotte)

Nel linguaggio più avanzato e formale (specialmente scritto), le relative clauses possono essere "ridotte" eliminando il pronome relativo e il verbo ausiliare *to be*, rendendo il testo più snello e diretto.

  • Con il Participio Presente ($V$-ing): Sostituisce una frase attiva.
    • Standard: The boy who is sitting next to Samuel is a programmer.
    • Ridotta: The boy sitting next to Samuel is a programmer.
  • Con il Participio Passato ($V_3$): Sostituisce una frase passiva.
    • Standard: The code which was written in Python is secure.
    • Ridotta: The code written in Python is secure.

💡 Preposizioni nelle Relative Clauses

In inglese informale, la preposizione che regge il pronome relativo viene solitamente spostata alla fine della frase (es. *The girl who I was talking to*). Nello stile formale, invece, la preposizione si posiziona subito prima del pronome relativo (es. *The girl to whom I was talking*).
